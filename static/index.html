    ◆ How it works

    Bounding boxes run locally in your browser (COCO-SSD) at full frame rate — no video ever leaves your machine. Every few seconds only the detection state (object names + confidences) goes to the backend, which asks Jev — TypeSafe AI's decision model — typed probability questions about it: is the person really there, is a detection likely false, did the detector miss something, is this worth flagging? Jev needs JEV_API_KEY set on the server; without it, detection still works fully and this panel mirrors local labels.
